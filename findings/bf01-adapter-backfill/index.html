حدود هذا الاستكمال

  • مجموعة الاختبار العامة فقط، وإعداد أداة التاريخ فقط.

English

bf-01 (pre-registered adapter back-fill, numbers only): the effect of our prompted-JSON adapter differs by model, so a model measured on one tool path cannot be compared fairly with one measured on the other. Four models measured on their own tool format only were run on both paths in one session (dental clinic WhatsApp front desk, 42 public scenarios × 3 runs per path, date-tool setup). Fully correct conversations, own format → adapter: Jais 3 7B 69.8% → 76.2% (+6.3 points, paired 95% CI -4.0 to +17.5); Qwen3 8B 68.3% → 65.1% (-3.2 points, paired 95% CI -15.9 to +10.3); Fanar 2 27B 55.6% → 61.1% (+5.6 points, paired 95% CI -2.4 to +13.5); Jais 3 3.7B 29.4% → 43.7% (+14.3 points, paired 95% CI 0.0 to +27.8). For Jais 3 3.7B the adapter raised success but emergencies handed to staff in time fell from 22/25 to 7/25. Reproducibility: each own-format path repeats a published run; no difference excludes zero, and Qwen3 8B and Jais 3 7B reproduced every conversation word for word on the same llama.cpp build. The common-setup table now shows both paths for every model that has both, sorted by the adapter column. Phone-like numbers were redacted after scoring; rescoring gives the same scorecards. Full details in the trial folder.
